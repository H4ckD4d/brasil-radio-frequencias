# Brasil Radio Frequencias

Base colaborativa de frequencias de radiocomunicacao
organizadas por estado, municipio e servico.

## Categorias
- Radioamador
- Aviacao
- Maritimo
- Radiodifusao

## Estrutura
dados/UF/municipio/frequencias.csv

## Integracoes planejadas
- Uniden SDS100 e SDS200
- SDR / HackRF
- CHIRP
- Exportacao CSV

## Qualidade dos dados
Cada registro deve indicar fonte, data, modalidade
e situacao de verificacao.

Frequencias publicadas nao significam transmissoes
ativas. Respeite a regulamentacao e a privacidade.
